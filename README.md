# gtap_pub_ag_rd_stock

This repository contains [Jin et al. (2026)](ADD), which presents an approach to construct public agricultural R\*D stocks that can be used in the [GTAP model](https://www.gtap.agecon.purdue.edu/default.asp) to assess the impact of public agricultural R&D investment. The main input is the WUR-ERS Global Research on Agriculture: Personnel & Expenditures (GRAPE) dataset, which contains public agricultural R&D expenditure series for 190 countries, spanning the period from 1960 to 2022 [(Van Dijk et al., 2025)](https://doi.org/10.21203/rs.3.rs-6463998/v1). The gamma distribution is used to aggregate the R&D expenditure series into R&D stocks, following the approach of [Alston et.al. (2011)](https://www.jstor.org/stable/41331212).

The code is written in R and is organized into two scripts and a series of input data files:

- `create_rd_stock`: This folder contains the main code to construct the public agricultural R&D stocks. It reads the input data, applies the gamma distribution to aggregate the R&D expenditure series, and outputs the constructed R&D stocks in a format suitable for use in the GTAP model.

- `input_data`: This folder contains the input data files, including the grape_v1.0.0.csv file (please check for updates in the link above), a mapping of iso3c country codes to GTAP regions and country grouping.

- `output_data`: This folder contains the output files generated by the code, including the constructed public agricultural R&D stocks for GTAP regions. The output files are in CSV and har format and can be used as input for the GTAP model to analyze the impact of public agricultural R&D investment on various economic outcomes.

- `figures`: This folder contains the figures that are presented in the paper.
