# gtap_pub_ag_rd_stock

This repository complements [Jin et al. (2026)](ADD), who present an approach to construct public agricultural R&D stocks that can be used in the [GTAP model](https://www.gtap.agecon.purdue.edu/default.asp) to assess the impact of public agricultural R&D investment. The paper applies the gamma distribution (see [Alston et al. (2011)](https://www.jstor.org/stable/41331212) and [Fuglie (2018)](https://onlinelibrary.wiley.com/doi/full/10.1093/aepp/ppx045) for more information) is used to aggregate the R&D expenditure series into R&D stocks. The main input is the WUR-ERS Global Research on Agriculture: Personnel & Expenditures (GRAPE) dataset, which contains public agricultural R&D expenditure series for 190 countries, spanning the period from 1960 to 2022 [(Van Dijk et al., 2025)](https://doi.org/10.21203/rs.3.rs-6463998/v1). This repository contains R code to create the public agricultural R&S stocks for all GTAP regions. It is organized using the following folder structure:

- `create_rd_stock`: This folder contains the main code to construct the public agricultural R&D stocks. It reads the input data, applies the gamma distribution to aggregate the R&D expenditure series, and outputs the constructed R&D stocks in a format suitable for use in the GTAP model.

- `input_data`: This folder contains the input data files, including the grape_v1.0.0.csv file , a mapping of iso3c country codes to GTAP regions and country grouping. Please check the data repository that is referenced in [Van Dijk et al. (2025)](https://doi.org/10.21203/rs.3.rs-6463998/v1) for potential updates of the GRAPE dataset.

- `output_data`: This folder contains the output files generated by the code, including the constructed public agricultural R&D stocks for GTAP regions. The output files are in CSV and har format and can be used as input for the GTAP model to analyze the impact of public agricultural R&D investment on various economic outcomes.

- `figures`: This folder contains the r scripts to reproduce the figures that are presented in the paper.
